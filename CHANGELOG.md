# Development history

KineScope is maintained as a continuously evolving research platform. Product names, APIs, and datasets do not carry release numbers. Git commits and immutable dataset manifests provide exact provenance.

## Current foundation

- Exact integer-valued mechanics for cubic twisty-puzzle lattices.
- Procedural convex geometry and Ghost-Cube-like shape modification.
- State-dependent rigid bandages and legality analysis.
- Interactive WebGL and deterministic server-side observation rendering.
- Public/private research episode generation and leakage controls.
- Six synchronized observation channels.
- Sixteen benchmark task families and eight evaluation splits.
- State-graph, mechanics-hypothesis, geometry, calibration, and evaluation analysis.
- JSON, JSONL, PNG, ZIP, OpenAPI, CLI, REST, Docker, and Vercel interfaces.

See the Git history for exact implementation chronology.
