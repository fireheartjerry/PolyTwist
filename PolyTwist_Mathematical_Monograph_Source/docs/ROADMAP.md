# Roadmap

**Status:** mathematics-first promotion plan  
**Date:** 2026-07-29  
**Canonical audit base:** `a970c65ab367b98ea380d48919c449bb63fa8638`

PolyTwist should not generalize by adding puzzle families one constructor at a time. The roadmap promotes mathematical capabilities only after their semantics, certificates, and failure modes are fixed.

## 1. Current implemented foundation

The repository currently provides:

- exact cubic logical mechanisms for sizes 2 through 9;
- convex shape-mod geometry from bounded half-spaces;
- translated and rotated orthogonal cut frames;
- exact signed-permutation orientations and quarter-turn actions;
- connected rigid bandages with state-dependent closure checks;
- transactional preview/commit, load, undo, redo, replay, and scrambles;
- deterministic browser and server rendering;
- synchronized observation channels;
- geometry and dynamics reports, bounded state graphs, and experiment ranking;
- public/private benchmark suites, evaluators, schemas, CLI tools, and REST services.

This is the reference specialization to preserve and verify. It is not the end-state mechanism language.

## 2. Promotion Gate M0: research foundation

**Status:** completed by the 2026-07-29 mathematics pass.

Exit condition: the mathematical target is precise enough that implementation work can be rejected for violating it.

## 3. Promotion Gate M1: exact cut and topology kernel

### Mathematical work

- freeze exact coefficient-domain requirements;
- define supported affine and bounded-degree semialgebraic carriers;
- specify normalization and equality of cut functions;
- prove compiler soundness for connected sign components;
- prove closure-incidence and trace correctness;
- handle redundant, coincident, tangent, and locally invisible carriers.

### Algorithmic work

- exact affine arrangement backend in fixed dimension;
- certified fallback backend for general supported semialgebraic cuts;
- output-sensitive trace extraction;
- canonical stratum IDs derived from normalized inputs and component certificates;
- independent checker for witnesses and incidences.

### Exit tests

- both rational ghost specimens reproduce every proved chamber and trace;
- disconnected equal-sign components remain distinct;
- exact results are invariant under input reordering and equivalent equation scaling;
- no floating-point tolerance changes topology.

## 4. Promotion Gate M2: physical-piece and seam kernel

### Mathematical work

- formalize admissible bond graphs/hypergraphs;
- prove piece regularity conditions;
- define mechanical seams after the bond quotient;
- define decorated-piece symmetries and state equivalence.

### Algorithmic work

- bond-component compiler;
- exact piece-boundary reconstruction;
- regularity, connectedness, and disjoint-interior certificates;
- seam extraction with raw-trace provenance;
- true solid unions or certified boundary representations.

### Exit tests

- current bandaged presets compile to equivalent physical pieces;
- bonded cut traces disappear mechanically but remain available as raw geometry;
- invalid teleporter bonds, self-intersections, and zero-volume pieces are rejected with witnesses.

## 5. Promotion Gate M3: configuration, joints, and docking

### Mathematical work

- define exact anchors, fixed bodies, joint relations, and gauge removal;
- define clearance and interior nonpenetration;
- define docked-state predicates and positive-dimensional docking families;
- characterize finite-slot specializations.

### Algorithmic work

- exact placement and assembly schema;
- joint/anchor constraint compiler;
- symmetry-aware canonical state representation;
- docking checker and certificates;
- compatibility adapter for the current signed-permutation state engine.

### Exit tests

- every current cubic state maps bijectively to a compiled atlas state orbit;
- symmetric-piece ambiguities normalize deterministically;
- invalid assembled configurations are rejected atomically.

## 6. Promotion Gate M4: turn paths and exact legality

### Mathematical work

- freeze state-indexed anchor semantics;
- formalize gate atomicity;
- prove specialized swept-collision criteria for important classes;
- define reverse-template and partial-bijection obligations;
- classify jumbling and intermediate docking behavior.

### Algorithmic work

- exact path language, including rational half-angle axial rotations;
- gate extrema and no-straddling certificates;
- bond-kernel checks;
- collision checker with specialized fast paths and exact fallback;
- endpoint docking and reverse verification;
- structured legality residuals.

### Exit tests

- safe endpoints with an interior collision are rejected;
- state-dependent legal masks are reproduced exactly;
- every accepted turn has a verified reverse;
- current quarter-turn transitions match the legacy engine on exhaustive bounded fixtures.

## 7. Promotion Gate M5: partial dynamics and canonical graphs

### Mathematical work

- define compiled inverse-semigroup and groupoid artifacts;
- prove state-graph derivation and group-action reduction;
- define graph quotienting under atlas automorphisms;
- specify exact finite-memory scramble laws.

### Algorithmic work

- partial-transition service;
- exhaustive/bounded graph generation with blocked-edge witnesses;
- exact shortest paths on bounded components;
- product-automaton scramble analysis;
- canonical graph and transition certificates.

### Exit tests

- total-domain fixtures reduce to ordinary group actions;
- bandaged/jumbling fixtures remain partial without fake sink states;
- independent replay verifies every exported edge and reverse.

## 8. Promotion Gate M6: certified rendering

### Mathematical work

- define exact face-to-mesh provenance;
- define approximation/error contracts;
- distinguish geometric visibility from sensor observability.

### Algorithmic work

- certified tessellation from exact piece boundaries;
- synchronized browser/server render manifests;
- visibility, occlusion, normal, depth, flow, and correspondence channels;
- renderer cross-checks and deterministic camera rigs.

### Exit tests

- every rendered primitive maps back to an exact face/stratum;
- renderers agree within declared rasterization contracts;
- no render artifact changes state, legality, or evaluator truth.

## 9. Promotion Gate M7: atlas-native benchmark

### Scientific work

- freeze one flagship active-identification protocol;
- freeze one transfer/compositional generalization protocol;
- derive task difficulty variables from atlas invariants rather than arbitrary feature vectors;
- establish identifiability and leakage controls;
- define public/private disclosure transforms.

### Platform work

- content-addressed atlas, state, proof, observation, and task artifacts;
- model-run manifests and event JSONL;
- active experiment service over finite hypothesis families;
- exact evaluator replay and certificate checking;
- intervention registry for corrupted observations, impossible states, and false action affordances.

### Exit tests

- each target is reproducibly derived from an atlas artifact;
- appearance/mechanics factorial controls are balanced;
- hidden mechanics are not leaked through IDs, serialization, filenames, or render metadata;
- passive and active baselines expose genuine information gain;
- benchmark items remain valid after renderer replacement.

## 10. Promotion Gate M8: noncubic and future mechanisms

Only after M1–M7 pass:

- dodecahedral and other polyhedral face-turners;
- corner-turning and edge-turning mechanisms;
- arbitrary plane families and nonorthogonal axes;
- curved algebraic cuts;
- partial-angle and jumbling turns;
- hidden cores, key pieces, latches, and conditional generators;
- procedural atlas grammars;
- positive-dimensional and hybrid docked-state spaces.

Each new family must be an atlas instance plus certificates. Family-specific mechanics code is a temporary experiment, never the canonical representation.

## 11. Sim-to-real track

This track begins only after atlas-native geometry and state are stable.

- calibrated multi-camera rigs and real video sequences;
- scan-to-atlas alignment with uncertainty sets;
- active reconstruction experiments;
- contact, tolerance, friction, and manipulation interfaces;
- robot gripper actions as additional partial paths;
- belief-state planning under observation uncertainty;
- sim-to-real evaluation with explicit geometry and sensor mismatch.

Real-world inference must preserve uncertainty rather than snapping every scan to whichever exact atlas happens to be emotionally convenient.

## 12. Research milestones

1. **Affine atlas paper core:** exact definitions, theorems, compiler certificates, rational specimens, and cubic-specialization equivalence.
2. **Swept legality paper core:** specialized exact collision certificates, partial dynamics, and state-dependent/jumbling fixtures.
3. **Active identification benchmark:** atlas-native hypotheses, experiment partitions, appearance/mechanics interventions, and calibrated model evaluation.
4. **General mechanism release:** noncubic and curved examples only after proof-carrying compilation is credible.

## 13. Immediate next work

1. Design the exact affine-atlas serialization and certificate schema.
2. Prove soundness of canonical connected-component IDs under equation rescaling and cut reordering.
3. Encode current cubic presets as atlas fixtures without changing runtime behavior.
4. Build an independent checker for affine trace and chamber certificates.
5. Prove a specialized convex axial-turn collision theorem.
6. Specify the compatibility theorem between legacy cubic states and atlas states.
7. Construct one exact dodecahedral specimen and one exact partial/jumbling specimen on paper before touching production code.

## 14. Non-goals

- accumulating named puzzle presets without a general representation;
- treating a mesh as canonical geometry;
- using endpoint noncollision as a substitute for swept legality;
- calling a permutation table a mechanism definition;
- adding arbitrary benchmark feature vectors because they correlate with difficulty on one dataset;
- claiming all semialgebraic algorithms are practical merely because they terminate before the heat death of the universe;
- rewriting the current engine before its specialization equivalence can be tested.
